# The stack, and why each piece

What the demonstration is built from, and the reason for each choice.

| Layer              | Technology                                                           | Why this one                                                                                                                                                                                                                             |
| ------------------ | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Schema             | [LinkML](https://linkml.io)                                          | A schema in YAML that generates JSON Schema, Pydantic, SQL and OWL from one source, with a validator and a URI per class and slot: one definition, every representation. JSON Schema alone has no semantics; OWL alone generates no code |
| Mappings           | SSSOM                                                                | The standard for mapping sets. A mapping is a reviewable table, not code, so each product's join can be counted and diffed                                                                                                               |
| Live platform      | ServiceNow PDI: Table API, Service Catalog API, scripted REST        | The one system that holds the record of the work, and the only live one, so the join key is real                                                                                                                                         |
| Access controls    | Veza OAA SDK (`oaaclient`); Immuta subscription-policy schema        | Representative controls with a public SDK and a public policy schema, so authority can be compiled out rather than described. Veza is a ServiceNow acquisition                                                                           |
| Other sources      | Armis, Moveworks, OpenTelemetry GenAI spans                          | The other acquisitions in the join, simulated from public documentation; each mapping is checked against the documented shape                                                                                                            |
| Projections        | OpenTelemetry Weaver, OCSF 1.9 schema server, Apache Ossie           | OpenTelemetry is already the common format for agent traces; OCSF is what SIEMs read; Ossie is the open semantic layer with `ai_context`. Each has its own validator, so the work's meaning is checked, not asserted                     |
| Store              | DuckDB                                                               | Embedded, no server, and loads the SQL LinkML generates                                                                                                                                                                                  |
| Agent              | [Claude Code](https://claude.com/claude-code) headless (`claude -p`) | Answers in a JSON Schema generated from the model, with tools disabled, so it can propose but never act (the no-lock-in reader alone gets read-only tools and `python3`); every prompt and answer is kept                                                                                                 |
| Compiled-rule test | node                                                                 | Runs the generated ServiceNow JavaScript under a Glide stand-in, so the compiled rule is tested against the replay engine before it reaches an instance                                                                                  |
| Build              | Python 3.12, uv, pytest, make                                        |                                                                                                                                                                                                                                          |
